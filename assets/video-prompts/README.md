# AI video-short prompts

Working prompts for generating short AI product-demo videos (Sora, Runway, Veo, etc.) for each 5280 Content product. Treat these as first drafts — tweak wording per the tool you're using.

Each product has its own file in this folder:

- `homepage.md` — 5280 Content brand reel
- `chairside.md`
- `excel-a-route.md`
- `territory-text.md`
- `massive-empire.md`

Companion hero-image / icon prompts (for a graphic designer or an AI image tool) live at `/docs/graphics-and-video-prompts.md` in this repo, so both are together the next time this comes up. The planned outline for the Massive Empire Fantasy Football subpages is also in `/docs`.
